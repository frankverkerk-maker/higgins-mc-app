## Summary

This report translates the Harvey-versus-Justitia gap analysis into an implementation-ready security and guardrail programme for Justitia Legal Council. It defines the target control, execution, evidence, and assurance planes; organisation and matter isolation; versioned Agent Manifests; plan-before-execution; approval gates; a default-deny Tool Gateway; evidence and citation validation; tamper-evident audit; governed memory; adversarial evaluation; release gates; and a ninety-day delivery roadmap.
